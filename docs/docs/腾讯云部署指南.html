包压缩包内容

解压后 index.html 为应用入口（全部界面/逻辑单文件），其余文件按相对路径引用，必须整体上传、保持目录结构：
  • index.html 应用本体 · sw.js 离线缓存（缓存键 quant-app-v41）· manifest.json PWA 清单
  • regime_breadth.json 市场宽度历史种子（近 60 交易日）——灯2 必需，清缓存/换机后立即补齐 20 日序列，勿删
  • reports/bucket-calib.html 桶分校准设计说明（9 处校准审计依据）
  • reports/桶分校准与双回测.html 全时段/近3年双口径对比回测报告
  • icons/ 桌面图标（180/192/512/maskable）· docs/ 本部署指南 · README.md · 评分说明.md

AEdgeOne Pages（Makers Drop）推荐 · 拖 ZIP 即部署

  1. 浏览器打开 https://pages.edgeone.ai/zh/drop
  2. 把 quant-app-v5.4-deploy.zip 直接拖进上传区（或点上传按钮选择；支持文件夹/ZIP，单文件 ≤25MB，文件数 ≤1000）
  3. 设置域名：可留空用默认免费域名，或输入喜欢的名字
  4. 点「立即部署」，获得 https 链接（EdgeOne 自动签发免费 SSL 证书）
  5. 中国境内用户需注册/登录腾讯云账号，登录后在仪表板才能拿到永久有效访问链接（未登录的临时链接仅 1 小时有效）
  6. 手机 Safari 打开该链接 → 分享 → 「添加到主屏幕」，即可像原生 App 一样全屏使用
后续更新：登录仪表板 → 找到项目 → 上传新版 ZIP 即覆盖更新；手机端打开页面后点左上角 ↻v41 徽标强制刷新（清缓存并注销旧 Service Worker）。

B腾讯云 CloudBase 静态网站托管控制台上传 / CLI 皆可

  1. 腾讯云控制台搜索「云开发 CloudBase」→ 开通环境
  2. 进入「静态网站托管」→「本地项目部署」→ 选择解压后的全部文件上传（上传到根目录，保持 reports/、icons/ 结构）
  3. 获得 https://环境ID.tcloudbaseapp.com 链接（默认 HTTPS），Safari 添加到主屏幕
可选 CLI 一键部署：npm i -g @cloudbase/cli → cloudbase login → 在解压目录执行 cloudbase framework deploy。

C腾讯云 COS 静态网站托管需手动开 HTTPS · 域名需备案

  1. 创建存储桶 → 基础配置开启「静态网站」功能，索引文档填 index.html
  2. 上传解压后的全部文件到桶根目录
  3. 绑定 CDN 加速域名并开启 HTTPS（PWA 必须 HTTPS，Service Worker 才生效）
  4. 自定义域名在中国大陆访问需完成 ICP 备案

D每日 SOP · 市场宽度（收盘定格）

灯2 用的市场宽度 = 上涨家数占比，盘中随时在变，必须用「收盘定格值」才能与回测同口径。因此 App 只在收盘后或次日凌晨打开时才抓取并写入当日宽度，盘中一律不写。

  • 15:25–24:00（盘后）：手机打开一次 App 停在首页即可 —— 约 1.5 秒后自动后台抓取当日收盘宽度（无需点击）。
  • 00:00–08:30（次日凌晨）：补录 —— 按「上一交易日」写入（当天没来得及打开时用）。
  • 09:30–15:00（盘中）：不抓、不写；灯2 继续用历史序列算 20 日均值。
  • 周末 / 节假日：指数未更新 → 自动跳过。
每日 3 步：① 收盘后开一次 App → ② 点「开始评分」→ ③ 需要留档就「导出 CSV」。无需再手工上传 regime_breadth.json（它只是历史种子）。

✓部署后自检清单

  • 浏览器打开为黑金界面，左上角版本徽标为 v41
  • 「评分规则」页需输入密码（jayce1024）解锁；底部可打开 reports/ 两份报告，并可见《每日 SOP · 市场宽度》《灯1/灯2 定义与非对称分级降仓》《导出 CSV 说明》等节
  • 点「开始评分」能拉取行情并出分；「导出 CSV」正常（首次会弹一次导出说明）
  • 评分结果含「小盘熊市两盏灯」行（灯1 中证1000 / 灯2 市场宽度），宽度取自收盘定格（收盘前则为「盘中14:45预估值」），并标注样本 N/20 日 + 最新日期；正常应显示最新交易日（如 2026-09-30），若显示很早的日期即为种子/抓取异常
  • 周末/节假日也能更新（v39 修复）：宽度标签统一取「指数最新交易日」，休市日打开会补记最近一个已收盘交易日；旧版在非交易日不会更新
  • 两个抓取时点（v40）：14:45–15:00 抓「盘中预估」（收盘前即可看到灯、来得及操作），15:25 后抓「收盘定格」并覆盖预估值；界面会标注该条是「盘中14:45预估值」还是「收盘定格」
  • 仓位建议卡随灯控联动：两灯全亮或宽度深弱（<42%）时单只/总仓显示 0%（空仓）、宽度偏弱（42–44%）显示半仓，并附「灯控×N（未降仓 X%）」对照
  • Safari 添加到主屏幕后，断网仍能打开应用壳（Service Worker 生效）

?常见问题

  • 部署后还是旧界面？点左上角 ↻v41 徽标强制刷新，会清理旧缓存并注销旧 SW。
  • 市场宽度（灯2）什么时候更新？两个时点：14:45–15:00 抓「盘中预估」（收盘前就能看到灯、来得及操作），15:25 之后再抓「收盘定格」并覆盖预估值；09:30–14:45 不写（早段噪声大）。建议 14:45 看一次、收盘后再打开一次。
  • 清缓存后宽度是否要从头累积？不会。包内 regime_breadth.json 提供近 60 交易日种子，启动即补齐 20 日序列。
  • 自定义域名打不开 / 报 404？确认域名已完成 ICP 备案并正确解析到托管/CDN。
  • 行情数据拉不到？行情走腾讯公网接口 web.ifzq.gtimg.cn，宽度走新浪 vip.stock.finance.sina.com.cn，均需联网获取，与托管平台无关；SW 策略已配置为这些域名永不缓存。
  • 报告页打不开？确认 reports/ 目录已随包上传且文件名未被改动（中文文件名保持原样）。
