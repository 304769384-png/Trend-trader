# 评分说明 · 十日线回踩战法 生产模型（对外版本 v41 / 交付 v5.4）

> 本说明与 PWA 应用 `index.html` 内 `scoreS1~S8`、`scoreS9`、`R9 检测`、`加分项` 逻辑**逐字一致**（六因子桶分校准评分：官方七因子桶分 × 去 S2 等比放大权重 + **9 处桶分校准**，无状态权重、**无风控乘数**；叠加 2026-09-15 定档的 S9/R9 扣分与 limit_vr 加分）。与回测权威 `strategy_v28.py` 逐字一致。
> 评分对象：用户输入的股票池；数据源：腾讯行情近 **60 日**前复权日 K；市场状态：小石大盘情绪接口逐日缓存（近 20 日滚动，**仅展示参考**）。

## 一、准入条件（先过滤，后评分）

对每只股票计算指标后，先检查以下 8 项条件，**任一不满足即剔除**：

| # | 条件 | 判定 | 不满足提示 |
|---|------|------|-----------|
| 1 | 近 20 日有涨停 | 近 20 日最高价 ≥ 前收 × 1.095（盘中触及口径） | 近 20 日无涨停 |
| 2 | 多头排列 | MA10 > MA20（gap > 0） | MA10≤MA20 |
| 3 | 当日缩量 | 量比 ≤ 0.80（当日量 / 前 5 日均量） | 量比>0.8 |
| 4 | 收于 MA10 之上 | 收/MA10 > 1.0 | 收/M10≤1 |
| 5 | 不远离 MA10 | 收/MA10 < 1.08（**硬过滤阈值**） | 收/M10≥1.08 |
| 6 | 当日阴线 | 收盘 < 开盘 | 非阴线 |
| 7 | MA10 位阶正常 | MA10 与 MA20 偏离 ≤ 10%（gap ≤ 0.10） | 位阶gap>10% |
| 8 | 收盘高于 MA20 | 收盘 > MA20 | 收盘≤MA20 |
| 9 | **T0 未跌停（v41 新增）** | 收盘涨跌幅 > −9.5%（创业板 > −19.5%），盘中触及但收回的不剔 | T0跌停 |

> **第 9 条依据（2026-10-09 定档）**：封死跌停 → 量比必然 ≤0.8（近5年 **123/123 笔全部通过**「缩量」准入，中位 0.69），「抛压衰竭」与「想割割不掉」在同一读数下无法区分；且跌停把收/MA10 砸进 **S1 最高分桶 1.03–1.04**——跌得越狠分越高。实证近5年 T0 跌停 123 笔 D1 **−2.98%** / 胜率 30.1%；紧邻桶 (−9.5, −8] 反而 **+0.97%**（全场最佳）→ 边界 −9.5% 为制度自然边界。回测侧同口径落地于 `engine_v2.is_tradable()`（永久口径，全史剔除 388 笔）。

## 二、架构与因子

**架构**：`总分 = Σ 六因子加权 + S9扣分 + R9扣分 + 加分`（无风控乘数）

- 参与因子（2026-09-02 定版）：**S1 / S3 / S4 / S5 / S6 / S8**（仅剔除 S2 量比）
  - S2 剔除依据：滚动方向稳定性 spearman=0.308<0.7（6.1-6 必过项），且含 S2 拉低 IC → 剔除
  - S5 涨停次数**保留**参与评分（主评分口径；同期备选方案曾剔除，按用户裁决保留）
- 权重 = 官方七因子权重去 S2 后**等比摊回满分**（×100/84.5≈1.185），与回测加权口径一致
- **舍入口径（一致性门禁 Phase 5，2026-09-02）**：各因子分与总分 `roundH(×10)/10` 半数取偶（银行家舍入），与 Python `round(t*10)/10` 逐位一致；曾因 JS `Math.round`（半数进位）在 t×10 恰为 x.5 时相差 0.1，已统一修复。

**桶分校准（2026-09-19 定档，与 `strategy_v28.CALIB` 逐字一致）**：共 **9 处**，依据 26 年全候选 **156,975 笔 D1 实证** + 近 5 年逐年独立确认。校准原则：D1 次日收益几乎中性或反向的桶下调、显著正收益且近 5 年稳健的桶上调（如 S6 ≥6 从 3.6 大幅上调至 10.0）。完整审计过程见 `reports/bucket-calib.html`。

### 扣分项与加分项（2026-09-15 定档，与回测 strategy_final.py 逐字一致）

**S9 未补跳空缺口扣分（阈值 1%→5% + 距离权重反转）**
- 定义：今日最低 > 昨日最高 且 之后（至评分日）未回补的跳空缺口
- 扣分档位：缺口 ≥10% 扣 10 · ≥7% 扣 8 · ≥5% 扣 6 · **<5% 不扣分**（小缺口无害甚至有利，旧规则误伤）
- 距离权重反转：距缺口底部 <30% ×0.3 · <60% ×0.6 · 更远 ×1.0 —— **悬空越远扣越多**
- 回测：缺口>5%未补 D1 -0.16%~-0.22%，区分度 -0.213pp（vs 旧规则 -0.052pp，提升约 4 倍）

**R9 涨停次日放量滞涨扣分（k=1.0 / h=5% / 扣 -10）**
- 定义：最近涨停日的次日，同时满足 ① 次日收阴 ② 次日量/涨停日量 ≥ 1.0（放量）③ 次日最高较涨停收盘冲高 ≥ 5%（冲高回落滞涨）→ 出货特征
- 扣分：-10 分（回测三档 10/15/20 几乎无差，取最小有效档）
- 回测：冲高阈值 3%→5% 区分度 -0.076→-0.121pp，三窗口组合层最优；宏盛画像内（pd=3 & 20日2板）ΔD1=-0.583%，把强势画像期望几乎清零

**加分项（limit_vr ∈ [5,6) 加 +3）**
- 定义：涨停放量比（涨停日量/前20日均量）落在 [5.0, 6.0) 加 3 分
- 回测：全量 +0.0121pp / 近1年 +0.02pp（弱市主要保护）；slope5≥0.08 / pullback=3 / volratio 0.4~0.8 等候选已全部证伪，不执行

## 三、市场状态（仅展示参考）

状态判定口径与回测状态机一致：**adv_ma20**（20 日上涨家数占比）× **lc_rate_ma20**（20 日涨停率）× **lc_std20**（20 日涨停家数标准差）。应用自动缓存每日市场情绪，累计满 20 日生效；样本不足 8 日按**震荡整固（中性）**展示。

**FINAL 模型不设状态权重**——评分与市场状态完全解耦，状态仅在推荐榜作参考展示，逻辑稳定、透明可复现。

## 四、总分与风控

```
总分 = Σ( S1 + S3 + S4 + S5 + S6 + S8 加权和 ) + S9(≤0) + R9(≤0) + 加分(≥0)   （无风控乘数）
```

**计算顺序（与回测 strategy_v28.score_v28 逐字一致）**：六因子加权和 → 半数取偶 1 位 → 加 S9 扣分 → 半数取偶 → 加 R9 扣分 → 半数取偶 → 加 limit_vr 加分 → 半数取偶。**不再乘任何风控系数**。

**推荐分层**：≥70 分 推荐 · ≥75 分 优选 · ≥80 分 精选（满分约 100.2）

**风险标注（仅展示，不参与评分）**：
- 当日跌停（≤ -9.5%）：标签「跌停」（旧版曾 ×0.4）
- 当日大跌（≤ -5%）：标签「大跌」（旧版曾 ×0.7）
- ST 股：标签「ST」（旧版曾 ×0.9）

**取消风控乘数依据（2026-09-19 定版）**：26 年全候选 156,975 笔 D1 审计实锤「超跌反弹」A 桶（跌停/大跌后次日）为正收益——旧乘数惩罚过度，反而压低本应高分的高胜率超跌反弹股；本版起评分与风险完全解耦，风险仅作人工参考。

> 市场宽度**不参与评分**，仅用于「小盘熊市两盏灯」的提示与**仓位建议降仓**。此处单独说明，便于每日操作对口径。

- **定义**：灯1 = 中证1000(000852) 收盘距 MA20 **< -2%**；灯2 = 市场宽度（上涨家数占比）MA20 **< 44%**（**< 42% 记为「深弱」**）。
- **非对称分级降仓（v38 实测定档，作为暴露系数压进仓位建议）**：① 两灯全亮 → **空仓**（×0）；② 宽度单灯 < 42%（深弱，中证1000 尚稳）→ **空仓**（×0）；③ 宽度单灯 42–44%（偏弱）→ **半仓**（×0.5）；④ 中证1000 单弱（宽度 ≥44%）→ **不降仓**（×1）。依据 `backtest-v15/regime_dereisk.py`：宽度单灯深弱近4年后20日 -3.46%（真风险）；中证1000 单弱近4年 中证1000<-8% 后20日仍 +3.11%（反弹区）—— 方向相反故非对称。**仅影响仓位建议、不改变选股结果。**
- **为什么「两个时点」**：盘中宽度随时在变（09:30 与 14:30 可完全不同），回测用的日频宽度取**每日收盘值**。为兼顾「入库口径一致」与「收盘前能操作」，App 在 **14:45–15:00** 抓一次**盘中预估**（界面标注「盘中14:45预估值」），**15:25 之后**再抓一次**收盘定格**并覆盖预估值；09:30–14:45 不抓。
- **每日 3 步**：① **14:45 后打开一次 App**（约 1.5 秒后台自动抓取，看「盘中14:45预估值」决定今天要不要按信号动手）→ ② **15:25 后再打开一次**（或次日凌晨，自动用收盘定格值覆盖预估值）→ ③ 点「开始评分」，需要留档就「导出 CSV」。
- **数据源**：灯1 = 腾讯指数日K（1 次请求）；灯2 = 新浪「沪深A股」快照二分定位上涨占比（约 8 次请求），失败回退同源 `regime_breadth.json` 历史种子（近 60 交易日）。
- **本地缓存**：宽度序列 `v8_regime_adv_v1`（最近 120 条，每条含 `pre` 标记盘中预估/收盘定格）· 两盏灯 `v8_regime_lights_v4`（同日缓存，含阶段号）· 抓取阶段 `v8_regime_adv_phase` · 市场过滤 `v8_mkt_filter_idx_v1`（同日缓存）· 弱市开关 `v8_mkt_alert_on`；SW 缓存键 `quant-app-v40`（仅缓存应用壳，行情/宽度接口永不缓存）；宽度种子 `regime_breadth.json` 随包发布（近 60 交易日，重建至 2026-09-30）。宽度抓取为**两个时点**：14:45–15:00 盘中预估（约 9 次请求 / 0.67 秒）→ 15:25 后收盘定格覆盖。
